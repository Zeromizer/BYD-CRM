Having connection issues? Click here for setup instructions

If you're getting connection errors:

  1. Check your URL: Make sure you're accessing via HTTPS or http://localhost (NOT file://)
  2. Configure Google Cloud Console:
    • Go to: Google Cloud Console
    • Click on your OAuth Client ID
    • Add your website URL to Authorized JavaScript origins
    • Add your website URL to Authorized redirect URIs
  3. Example configuration:
    • For GitHub Pages: https://yourusername.github.io
    • For local testing: http://localhost:8000
  4. Enable the API: Make sure Google Drive API is enabled in your Google Cloud project
  5. Check browser console: Press F12 and check the Console tab for detailed error messages
